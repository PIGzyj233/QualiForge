# Domain Docs

This repo uses a single-context domain documentation layout.

Agents should read:

- `CONTEXT.md` for project domain language and product concepts
- `docs/README.md` as the documentation index (product / architecture / operations / adr)
- `docs/adr/` for architectural decision records
- `docs/product/prd.md` for MVP product scope and delivered status
- `docs/product/roadmap.md` for deferred and future capabilities

There is no `CONTEXT-MAP.md` in the current layout.
